One poster that sums up a single day of world news: Saturday 21 November
2026. The front page leads with the COP31 climate talks in Antalya, which
ran past their deadline and stalled without a deal. Around that hero
story sit six panels covering the rest of the day — negotiators in Geneva
agreeing to draft rules on killer robots, NATO's Rutte travelling to
Poland, Gen Z strike action rolling across several countries, Seoul's
move to impeach its chief justice, Andy Burnham signalling he wants
Britain back in the EU, and a Barcelona trial reporting a cancer pill
that shrank tumours.

The image itself is `entry.png`. The small program in `main.ts` does
nothing more than carry that committed image into the output directory
the grader reads, so what is judged is exactly the poster stored here.

This repository is an entry in the
[news-image-20261121 bounty on make.fun](https://make.fun/bounty/news-image-20261121).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That writes `out/entry.png`, byte for byte the poster in this repo.
